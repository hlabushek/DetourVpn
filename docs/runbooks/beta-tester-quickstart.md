# Closed beta tester quick start — internal draft

**Статус:** внутренняя памятка. Не является разрешением на рассылку APK или
направление тестера через VPN. I-030 пока не принята как beta-ready.

## Вход в Android-приложение

1. Откройте выданную владельцем signed beta APK.
2. Нажмите **«Войти через Telegram»**, затем **«Открыть бота в Telegram»**.
3. Запустите Mini App из сообщения бота и получите одноразовый код.
4. Вернитесь в DetourVPN и введите код только в поле приложения.
5. После входа проверьте, что открылся экран аккаунта. Оставьте VPN выключенным.

При переключении в Telegram незавершённая попытка входа сохраняется на устройстве
в зашифрованном Android Keystore хранилище до срока её действия. Сам OTP не
сохраняется; после перезапуска приложения его нужно ввести вручную, пока он
действителен.

## Если вход не завершился

- Не отправляйте OTP, Telegram ID, ссылки из Telegram, пароль или скриншот с ними
  в чат поддержки.
- Сообщите владельцу только версию приложения и точный общий текст ошибки.
- Не включайте VPN и не направляйте пользовательский трафик через бета-узел.
- Не переустанавливайте приложение и не очищайте данные без согласования с
  владельцем.
- Для обращения используйте только заранее выданный владельцем приватный
  контакт. Если контакт ещё не выдан, остановитесь и запросите его у владельца
  лично, не публикуя обращение в общем чате.

## Как сообщить о проблеме

Передайте владельцу только версию приложения, модель Android без серийного
номера, основной номер версии Android, этап сбоя и точный общий текст ошибки.
Не отправляйте OTP, Telegram ID, номер телефона, скриншоты аккаунта, VPN-профиль,
конфигурацию, сетевые адреса, посещённые сайты или сведения о содержимом трафика.
Пока эта памятка ограничивает тест просмотром интерфейса, оставляйте VPN
выключенным. Не включайте Always-on/Lockdown и не используйте приложение для
чувствительных аккаунтов.

Диагностический пакет не отправляйте автоматически. Передача возможна только
после просмотра встроенного предпросмотра, вашего явного согласия и выбора
владельцем заранее согласованного приватного получателя.

## Доступ и ограничения

- Приглашение остаётся активным по решению владельца.
- Отзыв приглашения в текущем API отключает аккаунт и отзывает его сессии и
  туннели; это действие выполняет только владелец после согласования.
- Эта памятка не разрешает публичную или групповую рассылку APK.
- Поддержка и VPN/privacy acceptance ещё не завершены. Тест пока ограничен
  входом и просмотром интерфейса без подключения туннеля.
