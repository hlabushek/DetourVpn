# Closed beta tester quick start — internal draft

> **Устарело.** Актуальный комплект для 0.1.0-beta.25: `beta-tester-pack.md`.

**Статус:** памятка для приглашённого тестировщика. APK владелец публикует в
своём закрытом Telegram-канале; подключать VPN можно только после отдельного
разрешения владельца. I-030 пока не принята как beta-ready.

## Получить и установить APK

1. Откройте только закрытый канал, который лично указал владелец. Не используйте
   пересланные APK или ссылки из других каналов.
2. Скачайте `app-release.apk` из публикации владельца. В публикации должны быть
   версия `0.1.0-beta.1`, package `com.detourvpn.client` и SHA-256:
   `b6c1d1988279c5ca02b46fb7952f58f84870152d7fe18f912410264618bca746`.
3. Откройте скачанный файл и подтвердите установку Android. Если Android просит
   разрешить установку из Telegram или приложения «Файлы», разрешите её только
   для выбранного приложения; после установки отключите это разрешение.
4. Если Android сообщает о несовпадении подписи, ошибке установки или
   необходимости удалить другую версию приложения, остановитесь и напишите
   поддержке. Не удаляйте данные и не устанавливайте APK из другого источника.

Этот канал предназначен только для приглашённых тестировщиков. Не пересылайте
APK или invite-ссылку дальше.

## Вход в Android-приложение

1. Откройте выданную владельцем signed beta APK.
2. Нажмите **«Войти через Telegram»**, затем **«Открыть бота в Telegram»**.
3. Запустите Mini App из сообщения бота и получите одноразовый код.
4. Вернитесь в DetourVPN и введите код только в поле приложения.
5. После входа проверьте, что открылся экран аккаунта. Оставьте VPN выключенным.

При переключении в Telegram незавершённая попытка входа сохраняется на устройстве
в зашифрованном Android Keystore хранилище до срока её действия. Сам OTP не
сохраняется; после перезапуска приложения его нужно ввести вручную, пока он
действителен.

## Если вход не завершился

- Не отправляйте OTP, Telegram ID, ссылки из Telegram, пароль или скриншот с ними
  в чат поддержки.
- Сообщите владельцу только версию приложения и точный общий текст ошибки.
- Не включайте VPN и не направляйте пользовательский трафик через бета-узел.
- Не переустанавливайте приложение и не очищайте данные без согласования с
  владельцем.
- Для обращения напишите в Telegram **@DetourVpnHelper**. Используйте этот
  контакт только для поддержки DetourVPN; OTP и данные аккаунта не отправляйте.

## Как сообщить о проблеме

Передайте поддержке только версию приложения, модель Android без серийного
номера, основной номер версии Android, этап сбоя и точный общий текст ошибки.
Не отправляйте OTP, Telegram ID, номер телефона, скриншоты аккаунта, VPN-профиль,
конфигурацию, сетевые адреса, посещённые сайты или сведения о содержимом трафика.
Пока эта памятка ограничивает тест просмотром интерфейса, оставляйте VPN
выключенным. Не включайте Always-on/Lockdown и не используйте приложение для
чувствительных аккаунтов.

Диагностический пакет не отправляйте автоматически. Передача возможна только
после просмотра встроенного предпросмотра, вашего явного согласия и выбора
владельцем заранее согласованного приватного получателя.

## Доступ и ограничения

- Приглашение остаётся активным по решению владельца.
- Отзыв приглашения в текущем API отключает аккаунт и отзывает его сессии и
  туннели; это действие выполняет только владелец после согласования.
- Эта памятка не разрешает публичную или групповую рассылку APK.
- VPN/privacy и operational acceptance ещё не завершены. Тест ограничен
  установкой, входом и просмотром интерфейса; держите VPN выключенным до
  отдельного объявления владельца.

## VPN-этап (черновик; действует только после объявления владельца)

Этот раздел не разрешает включать VPN. Он применяется, когда владелец лично
объявит, что подписанная сборка beta.22 прошла его приёмку (ADR-084) и вам
выдана квота. Версию и SHA-256 для этого этапа укажет владелец в публикации;
ориентируйтесь только на них, а не на значения выше.

- Приложение подключает VPN только для выбранных приложений или для всего трафика.
  Настройка находится в разделе «Разделение трафика»; маршрутизации по доменам
  в этой бете нет.
- Начните с режима «Через VPN только выбранные» и добавьте один браузер.
- Окно соединения продлевается автоматически; при смене окна возможны короткие
  паузы. Если соединение закрылось, нажмите «Подключить» ещё раз один раз и
  сообщите поддержке, если оно снова не поднялось.
- Бесплатный объём на тестера: 5 GiB. Остаток виден на экране «Трафик».
- Не используйте бета-VPN для банков, рабочих и других чувствительных аккаунтов.
  Нет kill switch и защиты от утечек, Always-on/Lockdown не включайте. Узел один,
  без независимого мониторинга, IPv6 для выбранных приложений заблокирован.
- Любые сбои, странный расход трафика или подозрение на утечку сообщайте
  @DetourVpnHelper (версия приложения и общий текст ошибки, без адресов и логов).
  Владелец может сразу отозвать доступ.
