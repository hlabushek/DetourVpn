# Релиз беты одной командой

Для владельца: обычное окно PowerShell, папка проекта. Нужно свободное место на диске C: (не
меньше 4 ГБ) и подключённый по USB телефон, если нужна установка.

```powershell
.\scripts\release_beta.ps1 -Install
```

Что делает скрипт по порядку и останавливается на первой ошибке:

1. **Проверки:** тесты и сборка Mini App, тесты админки, контрактные тесты админки.
2. **Выкладка на сервер:** админка и API (`deploy_beta_admin_panel.py`, перезапускает только
   бета-API, при сбое откатывается сам), затем Mini App (`deploy_beta_mini_app.py`). Перед каждой
   выкладкой делается проверка только на чтение.
3. **APK:** подписанная сборка (`build_beta_apk.ps1`, дважды спросит пароль хранилища ключа, ввод
   скрыт; внутри форматирование, анализ, тесты, Android lint), проверка подписи и ID (отчёт в
   `docs/evidence/i-030-beta-apk-verify-*.json`), печать пути и SHA-256, установка поверх старой
   версии через `adb install -r` (с флагом `-Install`).

Флаги: `-NoDeploy` (без сервера), `-NoApk` (без APK), `-Install` (поставить на телефон),
`-ApiOrigin` (по умолчанию бета-API).

Скрипт отказывается работать с незакоммиченными изменениями: сборка всегда соответствует git.

## Что проверить на телефоне после установки

1. Иконка и название DetourVPN.
2. Вход по коду устройства; галочка согласия.
3. Три сервера с флагами; подключение; внешний IP; расход трафика.
4. Настройки → «Приложения вне VPN»: при включённом VPN предлагает отключить; исключённое
   приложение идёт мимо VPN (проверка «мой IP» в нём и в браузере).
5. Настройки → «Работа в фоне»: разрешить работу без ограничений батареи. Выключите экран на
   несколько минут при включённом VPN: подключение не должно оборваться («срок истёк»).
6. Админка: вход, вкладка «Приглашения», приглашение второго аккаунта Telegram до статуса «Вошёл».

## Откат

- Админка/API: скрипт сам откатывает файлы и перезапускает API при сбое выкладки; копии прежних
  файлов лежат на хосте в `/root/detourvpn-pre-admin-<id>`.
- Mini App: прежний релиз остаётся на хосте, скрипт при сбое возвращает прежнюю строку в `api.env`.
- Приложение: установить предыдущий APK (`adb install -r` работает при том же ключе подписи и не
  меньшем versionCode; при откате на меньший код сначала удалить приложение).
