# Комплект для тестера беты (актуально для 0.1.0-beta.24)

Заменяет устаревшую памятку `beta-tester-quickstart.md` (она описывает beta.1 и запрет включать
VPN). Для каждого тестера нужно три вещи: **APK**, **сообщение ниже**, **приглашение в админке**.

## 1. Что отправить

- Файл APK: `apps/client/build/app/outputs/flutter-apk/app-release.apk` (отправлять в Telegram как
  **файл**, не как фото). Только подписанная сборка из `scripts/release_beta.ps1`.
- SHA-256 и версию: `0.1.0-beta.24`, package `com.detourvpn.client`. Хеш актуального файла:
  `Get-FileHash apps\client\build\app\outputs\flutter-apk\app-release.apk -Algorithm SHA256`.
- Ссылку на бота (она подставляется в готовый текст на вкладке «Приглашения» в админке).

## 2. Сообщение тестеру (скопировать и отправить)

> Привет! Приглашаю в закрытый тест DetourVPN. Это тест без гарантий: возможны сбои. Не используй
> его для чувствительных аккаунтов.
>
> **Установка.** Скачай файл (приложен), открой его. Android спросит разрешение на установку из
> Telegram: разреши, после установки это разрешение можно отключить.
>
> **Доступ.** Открой бота @<имя бота> и нажми кнопку приложения (Mini App). Если там написано
> «Доступ пока не открыт», нажми «Скопировать ID» и пришли мне это число. Я тебя добавлю. После
> этого открой Mini App ещё раз.
>
> **Вход в приложение.** Открой DetourVPN, поставь галочку согласия, нажми «Войти через Telegram»,
> затем «Открыть бота», запусти Mini App и получи код. Вернись в приложение и введи код. Код
> никому не пересылай.
>
> **Подключение.** Выбери сервер (Хельсинки, Германия, Нидерланды) и нажми «Подключить»; Android
> попросит разрешить VPN. Для проверки открой любой сайт «мой IP»: адрес должен быть страны сервера.
>
> **Чтобы не обрывалось.** Настройки → «Работа в фоне» → разреши приложению работать без
> ограничений батареи.
>
> **Приложения вне VPN.** Настройки → «Приложения вне VPN»: отмеченные приложения пойдут мимо VPN
> (изменять можно только при выключенном VPN).
>
> **Что собирается.** Твой Telegram ID, список устройств и расход трафика. Сайты и DNS не
> собираются. Адрес подключения может попасть в технические журналы до 7 дней. Тебе доступно
> 5 ГиБ трафика. Аккаунт можно удалить в профиле приложения.
>
> **Если что-то не работает**, напиши мне: версию приложения (Настройки), что нажимал и текст
> ошибки. Не присылай код входа и скриншоты с ним.

## 3. Порядок для владельца

1. Отправить APK и сообщение.
2. Тестер присылает свой ID (число из Mini App). Принимать только числа.
3. Админка → «Приглашения» → вставить ID и пометку (псевдоним) → «Добавить в бету».
4. Попросить тестера открыть Mini App снова и войти в приложение. Статус в списке станет «Вошёл»;
   стартовые 5 ГиБ выдаются автоматически при первом входе. Проверить во вкладке «Пользователи».
5. После пилота или при проблемах: «Отозвать…» (потребуется ID этого человека).

## 4. Чего не обещать

Гарантий работы, обхода блокировок при строгих списках разрешённых адресов, Always-on и защиты от
утечек (kill switch). Этот комплект не заменяет независимую проверку внешнего IP, DNS/IPv6 и учёта
трафика (см. `docs/beta-launch-checklist.md`).
