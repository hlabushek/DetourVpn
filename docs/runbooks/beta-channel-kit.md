# Закрытый канал беты: оформление, поддержка, первый пост

Готовые тексты для копирования. Картинки лежат в `docs/assets/channel/`:
`channel-avatar-640.png` (аватар канала) и `post-banner-1280x720.png` (картинка к первому посту).
Все тексты написаны под фактическое состояние беты: 3 сервера, 5 ГиБ на тестера, хранение
технических журналов до 7 дней, без гарантий и без kill switch.

## 1. Канал

Создать: Telegram → «Создать канал» → **Приватный** (доступ только по ссылке-приглашению).

- **Название:** `DetourVpn · закрытая бета`
- **Фото:** `channel-avatar-640.png`
- **Описание** (лимит 255 знаков, здесь 206):

```
Закрытый тест DetourVpn: приложение для Android, новости версий и инструкции. Это бета без гарантий, не для банков и рабочих аккаунтов. Вопросы и сбои: @DetourVpnHelper. Файл приложения берите только здесь.
```

Настройки канала:

- Тип: приватный; ссылку-приглашение не публиковать, выдавать лично. Включить «Запретить сохранение и пересылку контента» (защита от утечки APK).
- Комментарии и реакции: комментарии выключены (отзывы идут в поддержку, а не публично).
- Подписи к постам: выключены.
- Закрепить: первый пост (раздел 4).
- Администраторы: только владелец.

## 2. Профиль поддержки @DetourVpnHelper

Это обычный аккаунт Telegram, который открывает владелец. Настройки → «Изменить профиль»:

- **Имя:** `DetourVpn · поддержка`
- **Фото:** `channel-avatar-640.png`
- **О себе** (лимит 70 знаков):

```
Поддержка закрытой беты DetourVpn. Коды входа не присылайте.
```

- Приватность → «Кто может добавлять меня в группы»: «Мои контакты» (чтобы не втягивали в чужие группы).
- Автоответ (Telegram Premium/Business, если есть; иначе просто закрепить в себе «Сохранённом»):

```
Здравствуйте! Напишите: 1) версию приложения (Настройки), 2) что нажимали, 3) текст ошибки. Не присылайте код входа, скриншоты с ним и адреса сайтов. Отвечу, как смогу.
```

- Включить автоудаление сообщений в чате поддержки через 7 дней (так записано в политике хранения беты).

- **Edit Name:** `DetourVpn`
- **Edit About** (лимит 120):

- **Edit Description** (лимит 512, показывается при первом открытии бота):

Как начать: откройте приложение, нажмите «Войти через Telegram», вернитесь сюда и запустите кабинет. Если написано «Доступ пока не открыт», нажмите «Скопировать ID» и отправьте число в поддержку: @DetourVpnHelper.

Код входа никому не пересылайте.

- **Edit Botpic:** `channel-avatar-640.png`
- Menu Button: оставить кабинет (Mini App).

## 4. Первый пост (закрепить)

Картинка: `post-banner-1280x720.png`. Текст длиннее 1024 знаков и не помещается в подпись к картинке:
сначала отправить картинку, затем текст отдельным сообщением (закрепить его), затем файл:

```
DetourVpn · закрытая бета 0.1.0

Привет! Это первый выпуск приложения для Android. Тест без гарантий: возможны сбои, не используйте его для банков и рабочих аккаунтов.

Как начать
1. Скачайте файл ниже и откройте его. Android спросит разрешение на установку из Telegram: разрешите, после установки его можно отключить.
2. Откройте бота @uysdgyfudf_bot и запустите кабинет. Если написано «Доступ пока не открыт», нажмите «Скопировать ID» и пришлите число в @DetourVpnHelper: я добавлю вас в бету.
3. В приложении поставьте галочку согласия, нажмите «Войти через Telegram» → «Открыть бота», получите код в кабинете и введите его в приложении. Код никому не пересылайте.
4. Выберите сервер (Хельсинки, Германия, Нидерланды) и нажмите «Подключить». Проверить можно на любом сайте «мой IP»: адрес должен быть страны сервера.

Чтобы не обрывалось
Настройки → «Работа в фоне» → разрешите приложению работать без ограничений батареи.

Что доступно
Бесплатный объём на тестера: 5 ГиБ. «Приложения вне VPN» (Настройки): отмеченные приложения пойдут мимо VPN, менять можно при выключенном VPN.

Что собираем
Ваш Telegram ID, список устройств и расход трафика. Сайты и DNS не собираются. Адрес подключения может попасть в технические журналы до 7 дней. Аккаунт можно удалить в профиле приложения.

Чего не обещаем
Гарантий работы, обхода строгих списков разрешённых адресов, Always-on и защиты от утечек (kill switch).

Что-то не работает? @DetourVpnHelper: версия приложения, что нажимали и текст ошибки. Код входа и скриншоты с ним не присылайте.

Файл приложения никому не пересылайте, приглашение выдаётся лично.
```

Подпись к файлу APK (отправлять **файлом**, не фото):

```
DetourVpn 0.1.0-beta.<N> · Android 7+
SHA-256: <хеш>
```

Версию и хеш брать из команды (PowerShell в папке проекта):

```powershell
Get-FileHash apps\client\build\app\outputs\flutter-apk\app-release.apk -Algorithm SHA256
```

**Перед публикацией:** убедиться, что версия в подписи совпадает с версией в самом файле (иначе
тестеры сверят хеш и увидят расхождение). Сборка должна быть создана скриптом `scripts/release_beta.ps1`
из закоммиченного состояния (см. `beta-release.md`).

## 5. Порядок выхода

1. Создать канал, аватар, описание, настройки (раздел 1).
2. Оформить профиль поддержки (раздел 2) и бота (раздел 3).
3. Опубликовать картинку с текстом, закрепить, затем отправить APK файлом.
4. Сначала пригласить 1–2 знакомых (см. `beta-tester-pack.md`, раздел 3), потом остальных.
5. Новые версии публиковать новым постом с файлом и хешем; старый файл удалять из канала.
