# ADR-022: техническая приёмка I-011 и границы выпуска

Status: Accepted, 2026-10-19.

ROADMAP определяет I-011 как Android native tunnel POC с реальным egress;
ADR-019 уточняет connect/disconnect, egress, DNS/IPv6, отказ permission,
network switch и реальный peer revoke. Эти условия теперь измерены на Pixel
8 Pro/API 37 и согласованном staging, включая удаление peer при работающем
движке и прекращение трафика телефона. Поэтому технический I-011 принят.

Ранее checklist смешивал эти условия с более широкими release gates I-002.
Лицензионная модель, полный SBOM/NOTICE и независимый security review остаются
условиями публичного выпуска; этот POC их не закрывает. Ни один APK не публикуется.

Матрица наблюдений остаётся ограниченной: принудительный deep Doze IDLE/resume
пройден, естественный длительный hardware suspend не измерен. Проверен отказ
нового VPN permission; отзыв разрешения при активном VPN не измерен (изменение
appops само по себе его не доказывает). DNS — выборка трёх запросов, IPv6 —
HTTPS-пробы. Эти ограничения сохраняются в отчёте, не объявляются пройденными
и должны учитываться при полноценном Android клиенте/выпуске.

После потери узла disconnect восстановил IPv4 и IPv6 в повторном прогоне;
после полного отключения/возврата физических сетей VPN восстановил egress.
Первая неудачная попытка восстановления сохранена в истории. Автоперевыдача
профиля после замены ephemeral server key не реализована и не заявляется.

Следующий issue — I-012. Проверенный фиксированный staging controller не является
node daemon/protocol. Без durable command/ack, proof владения ключом и quota
lease нельзя выдавать пользовательский ready config или обещать durable revoke.
Техническая приёмка I-011 не отменяет эти условия ADR-016.
