# ADR-027 — I-015: серверные награды

Принято 2026-10-21. Бренд: DetourVpn. Только daily/clicker, без Mini App.

- Календарные сутки UTC, время PostgreSQL после блокировки владельца. Daily —
  максимум один успешный claim за сутки; clicker — count и bytes cap, cooldown
  между успешными начислениями, включая границу суток. Лимиты общие для аккаунта.
- Один активный конфиг на тип, окно [starts_at, ends_at), eligibility — active
  authenticated user. Нет конфигов по умолчанию: себестоимость ещё не утверждена.
  Новые правила включаются оператором БД после экономической проверки; публичного
  endpoint изменения правил нет. Нельзя менять тип существующего правила.
- User row lock общий с ledger/usage/tunnel accounting; rule SHARE lock защищает
  конфиг на время операции. Claim + ledger credit коммитятся атомарно. Снимки
  типа/суммы/даты остаются в append-only claims, смена конфигурации не обнуляет cap.
- Уникальный (user, idempotency_key). Успешный повтор возвращает исходный receipt
  даже после отключения/изменения правила или смены дня; другой rule — conflict.
  Отказы не резервируют ключ и не создают строки: повтор проверяет eligibility
  заново. HTTP caller обязан сохранять ключ запроса с неизвестным результатом
  и повторять его; UX/durable retry будущей Mini App определяются в I-017.
- Отдельный rate limit 120 запросов/мин на аккаунт, 3000/мин глобально (existing
  digest buckets), включая неуспешные claim. Это ограничение автоматизации, не
  доказательство участия человека и не защита от ферм аккаунтов.
- Ledger source `reward`, source_id = claim UUID; положительный credit only.
  История квоты служит историей наград. Никаких значений награды от клиента.
- Downgrade запрещён при наличии claims/reward operations; ledger не удаляется.
  Перед ручными изменениями — backup; production rollout вне этой issue.
- По прямому разделению интерфейсов владельцем I-015 реализует серверную
  геймификацию, а экран бонусов принадлежит будущей Mini App I-017. Обычное
  приложение сохраняет VPN/traffic/settings scope; в нём добавлены только
  распознавание reward в истории и Soft Orbit tokens для затронутого quota экрана.
  Light/dark; palette coral/lavender/turquoise/gold, независимые error/warning.
  Существующий roadmap DoD «телефон ↔ БД» остаётся открытым интеграционным gate,
  не основанием добавлять кабинет/кликер в обычное приложение.
