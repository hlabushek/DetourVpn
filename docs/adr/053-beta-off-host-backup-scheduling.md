# ADR-053 — fail-closed daily backup target for beta

Статус: принято и развернуто на изолированном beta API 2026-10-26. Копии хранятся
на ПК владельца; Windows-задача запускается раз в сутки в 07:00 местного времени.
Первый плановый запуск задачи ещё ожидается. S3 и платное хранилище не используются.

## Решение

Для beta control plane повторно использовать I-016 `make_backup`: PostgreSQL
snapshot выгружается в custom dump и шифруется Fernet до сохранения. Целевое
хранение на данном этапе — каталог на компьютере владельца. Новая команда
`scripts/import_beta_backup.py` проверяет Fernet-аутентичность уже полученного
`.enc` файла и атомарно создаёт уникальную локальную копию; исходник не удаляется.
Передача выполняется по pinned SSH identity: сервер создаёт единственный
зашифрованный архив в закрытом staging-каталоге, локальный скрипт скачивает его
и проверяет Fernet-аутентичность. Ключ на ПК защищён ACL, а на beta API хранится
в отдельном каталоге с узкими правами; общий secrets-каталог не расширялся.

Частота для тестовой беты — один запуск в сутки. Если ПК выключен в заданное
время, `StartWhenAvailable` позволит выполнить задачу при его доступности и
вошедшем пользователе. Путь к копиям и ключу не хранится в репозитории.

## Последствия и ограничения

- Повторно используется существующий проверенный encryption/restore формат;
  новая криптография и зависимость не добавляются.
- Локальный PostgreSQL integration test проверяет TEST ONLY dump; отдельный
  restore drill подтвердил фактический beta archive в disposable PostgreSQL.
  Beta DB для restore не использовалась; данные/идентификаторы не выводились.
- Компьютер владельца — единственная off-host копия для текущего тестового этапа;
  это не DR и не гарантия непрерывного восстановления. S3, внешний монитор и
  уведомления сейчас не нужны.
- Импортированный архив сохраняет Fernet-аутентифицированный формат и не
  раскрывает содержимое. Ключ остаётся в локальном файле владельца, путь не
  пишется в репозиторий.
- Первая копия с beta host прошла локальную проверку и restore drill в disposable
  PostgreSQL. Windows-задача зарегистрирована, но её первый плановый запуск ещё
  не подтверждён. Автоудаление копий и независимый монитор не настроены.
- На beta host установлен только PostgreSQL 17 client и backup-only systemd
  service; API и DB/container не перезапускались. Systemd timer template не
  включён: расписание выполняет компьютер владельца.
- По отдельному разрешению владельца затронут только beta API host и локальная
  Windows-задача. B/production, staging A, VPN node, schema/data, DNS, платежи и
  внешние аккаунты не затрагивались.
