## Navigation and motion (2026-11-09)

- Bottom navigation in both apps is a floating "liquid glass" pill: backdrop blur, translucent
  tint, specular top edge and a glass lens that flows to the selected tab and stretches mid-flight
  (`lib/ui/glass_nav.dart`, `.glass-nav` in `style.css`). Drawn in Flutter/CSS, no platform API.
- Motion tokens in `lib/ui/motion.dart`: tab fade-through, pushed pages fade + slide, staggered card
  entrance, orbit colours morph between states, progress bar and ring fill, button/state
  cross-fades, card press feedback, animated theme switch. Mini App mirrors this in CSS.
- All animations are finite except the "connecting" arc (and a slow planet float in the Mini App);
  both apps switch motion off when the system asks to reduce motion.

## Orbit artwork (2026-11-09)

- The orbit is raster artwork, not a vector painter: 4 states (idle, connecting, connected, error)
  × 2 themes, generated by the owner with ChatGPT from the Soft Orbit reference (owner's output,
  no third-party licence). Glass body only — icons and text are drawn in code on top.
- Processing: real alpha from the source PNGs; every state registered (scale + offset by body-mask
  IoU) to one body position on a 960×720 canvas; WebP, metadata dropped.
  Flutter: `apps/client/assets/orbit/` (~450 KB, all 8). Mini App: `src/assets/orbit/`
  (idle + error per theme, 480×360, ~70 KB), chosen by theme in CSS.
- States cross-fade (600 ms); only the dashed "connecting" ring rotates. The selected server moved
  from inside the orbit to the "Сменить регион" row (flag + name).
