# VPN Startup Kit — 15 октября 2026

Этот комплект можно перенести в корень приватного GitHub-репозитория и открыть в Codex.

1. **TECHNICAL_SPEC.md** — продуктовые требования, архитектура, API, модель данных, информационная безопасность, критерии приёмки.
2. **ROADMAP.md** — порядок работы, спринты, issue backlog, критерии перехода и риски.
3. **AGENTS.md** — обязательные ограничения и правила работы Codex.
4. **CODEX_START_PROMPT.md** — готовый первый запрос для Codex.

Первое действие: создать пустой приватный репозиторий, скопировать эти файлы в его корень, запустить Codex с промптом из `CODEX_START_PROMPT.md`. Начать с issue I-001, **не** с генерации приложения целиком.

Дата документации: 2026-10-15. Перед продакшеном заново проверить актуальность правил, лицензий и сетевых движков.
