## Существенный риск, который нужно решить владельцу

Бета-APK встраивает Amnezia Box (`THIRD_PARTY_NOTICES.md`): **GPL-3.0-or-later с дополнительным
условием об имени**. При раздаче APK тестерам, даже по приватной ссылке, нужно предоставить
соответствующий исходный код, включая локальный патч. Распространяется ли GPL на остальной код
приложения (клиент линкуется с движком в одном APK), в репозитории не решено: это вопрос для
юриста, а юридический обзор отключён решением владельца. Это осознанный риск (ROADMAP §9);
минимум для беты: хранить архив исходников `amnezia-box-v1.260910.0-src.zip` (в `third_party/`
его нет, лежит только `source-lock.json` с SHA-256) и патчи и выдавать тестеру по запросу.
`docs/licensing-checklist.md` по-прежнему даёт NO-GO по выпуску, этот аудит его не снимает.
