# I-011 — Android native tunnel POC

Статус 2026-10-19: **технический native POC принят**, граница — ADR-019/022.
Это не готовый пользовательский VPN и не разрешение публичного выпуска.

- [x] Pinned GoBackend-only SDK; native adapter v1; private key только на телефоне.
- [x] Debug APK, unsigned release APK и AAR; 7 unit tests, lint 0 errors/1 прежний warning.
- [x] Native/parser/security и system permission-denial checks на физическом телефоне.
- [x] Одобренный WAN endpoint, fresh sandbox preflight и исправленный snapshot v2.
- [x] Реальный forced-stop rollback: все 7 проверок состояния совпали.
- [x] Реальный 600s deadline: Result=timeout, ExecStopPost=0, все 7 проверок совпали.
- [x] Native UP, fresh handshake, egress совпадает со staging и отличается от baseline.
- [x] IPv6-only HTTPS до VPN работает, под VPN не работает, после normal disconnect работает.
- [x] DNS sample: 3 generated queries, наблюдались только ожидаемые Cloudflare resolvers.
- [x] Wi-Fi → cellular → Wi-Fi; egress остаётся staging. Wi-Fi/mobile settings восстановлены.
- [x] Normal disconnect: native DOWN, обычные IPv4/IPv6 восстановлены.
- [x] При stop dedicated test node трафик перестаёт проходить при ещё UP клиенте.
- [x] Test node остановлен/очищен, profile files удалены, временный sudo grant отозван.
- [x] Отдельный peer remove при active/ready движке, Pixel native UP, обе IP-пробы
      закрыты. Повторный revoke успешен. Direct UAPI исправление не расширяет sandbox.
- [x] После полной потери физических сетей их возврат восстановил VPN egress.
- [x] После потери узла disconnect восстановил обычные IPv4/IPv6 в повторном прогоне.
- [x] Forced deep Doze: IDLE наблюдался, resume сохранил handshake/egress.

Непроверенные границы: естественный длительный hardware suspend, системный отзыв
permission при активном VPN, DNS всех приложений. License inventory/SBOM/NOTICE
и независимый release/security review остаются gates публичного выпуска.
Прежние неудачные прогоны сохранены. Автоматическая перевыдача профиля после
смены ephemeral server key не реализована. Эти границы описаны в ADR-022.

Следующая issue — I-012: versioned peer protocol, durable outbox/ack и реальная
выдача/отзыв. Проверенный staging controller не заменяет production node agent.
