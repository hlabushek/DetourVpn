# I-006 — Devices public keys

Scope: authenticating user's Android public-key registry; owner-scoped read/list,
idempotent registration, active limit, family binding, revocation, composite FK.
Не включает выдачу VPN config, node agent, native key generation или Flutter UI.

Решения и ограничения: ADR-013. Migration 0003. API contract в OpenAPI.
Acceptance: чужие IDs не читаются/не отзываются; extra private/owner fields отвергаются;
same-key/concurrent registration не создаёт duplicates; active limit атомарен;
device revoke закрывает все связанные family, в том числе при concurrent refresh.

Tests используют real PostgreSQL и clearly synthetic public-key-shaped bytes;
auth fixture использует только test FakeTelegramSender. Ни live bot, ни native
keypair/VPN от этих тестов не следуют. Результат: verification-identity-stage.md.
Следующий инженерный issue: I-007 quota ledger; gates phase 1 отдельно в ROADMAP.
