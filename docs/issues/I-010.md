# I-010 — One test node deploy

Состояние 2026-10-19: **DONE — bounded staging test-node acceptance verified**.
Канонический критерий ROADMAP: repeatable provisioning. I-009 — prerequisite;
Android/новый внешний egress — I-011, публичный tunnel API — I-012.

## Объём и граница приёмки

Один одобренный Ubuntu staging host: pinned бинарники и лицензии размещаются
воспроизводимо; реальное исполнение на этом VPS проверяется обменом AWG peers
в изолированных namespaces. После теста временные peer, ключи и интерфейсы
удаляются; release остаётся установленным. Постоянно подключённый пользователь,
WAN ingress и рабочий Android VPN этим issue не подтверждаются. ADR-018
объясняет эту границу и оставшиеся условия I-011.

- [x] Финальный `staging-acceptance.yml` на VPS: installation/repeat + 4 runs.
- [x] На VPS: handshake/пакеты/peer removal и оба failure cleanup подтверждены.

- [x] Transient units удалены, новый датированный live receipt прочитан и проверен.
