# I-023 — административный backend и интерфейс

Статус: локальный API/UI реализован и проверен; Linux interactive bootstrap,
постоянный HTTPS и remote/physical эксплуатация ещё не приняты.
Файлы: admin.py, db/models.py, config/main, migration 0013, scripts/admin_bootstrap.py,
apps/admin/static, OpenAPI и тесты; ADR-036/runbook/verification.
Риски: обход MFA, brute force, повтор OTP/grant, plaintext seed, XSS/int64 rounding,
потеря audit при rollback. Existing ledger/subscriptions/outbox переиспользуются.
Тесты: real PostgreSQL MFA/replay/rate limits/RBAC, negative auth, idempotency races,
rollback/audit immutability, plan/subscription/device grants/revokes, migrations,
конфигурация default-disabled, static CSP и browser smoke без реальных credentials.
