# I-013 — Flutter connect UI

Назначена пользователем 2026-10-20. Зависимости: технически принятые I-011/I-012.
Scope/решения: ADR-025. Статус: технически принят 2026-10-21 в ограниченном
staging-контуре (один узел, lease до 60s/1 MiB). Реальный Flutter/Android
handshake и egress, Disconnect, remote revoke, expiry и cleanup подтверждены
`docs/evidence/i-013-staging.json` (`passed=true`). Подробные результаты и
непроверенные сценарии — `docs/verification-i-013.md`. Production/public release
этой приёмкой не подтверждаются; Telegram delivery в harness — TEST FAKE ONLY.

Финальная обычная сборка завершена 2026-10-21: исправлены registrant release и
неполные debug Gradle lock configurations; полный build/check script прошёл.
Обычный debug APK проверен, установлен и открыт на Pixel 8 Pro (экран настройки
без API origin). Receipt: `docs/evidence/i-013-final-app.json`; свежий аудит APK:
`docs/evidence/i-013-apk-audit.json`. VPS-прогон не повторялся; I-014 не начат.

## Acceptance

- Реальный Flutter UI → platform channel v1 → existing AWG GoBackend/VpnService.
- Вход через auth/start/verify, device registration и key proof без private-key export.
- API create с idempotency key, ожидание node ACK/config, Connect/Disconnect.
- disconnected/connecting/connected/reconnecting/failed из native/API данных.
- Permission denial/cancellation, double tap, delayed request, remote revoke,
  unavailable API, quota refusal, lease expiry не дают ложный connected.
- Темы, крупный шрифт, scroll, semantics; available integer bytes с freshness.
- Dart analyze/Flutter tests, native build/lint/unit, physical end-to-end.
- Ограничения staging и ручные действия явно документированы.

Полный quota/history UI — I-014. Каталог регионов/API discovery, persistent
credentials/keys, multi-node fleet, automatic renewal и release/publishing
не входят в I-013; существующий single-peer 60s gate I-012 сохраняется.

Планируемые файлы: `apps/client/**`, SDK path fix в
`apps/android/tunnel/build.gradle.kts`, `scripts/install_flutter.ps1`,
`scripts/build_flutter_client.ps1`, runbook/verification/ADR-025, ROADMAP/.gitignore.
Acceptance harness: `scripts/run_i013_android.ps1`,
`services/api/tests/test_i013_android.py`, sanitized evidence receipts.
Тестовые harness/fakes находятся только в test/integration_test; production
APK не содержит dev credentials, scripted test provider или HTTP bypass.

Security: ключ/token/profile не логируются и не сохраняются; backup выключен;
secure window; HTTPS с системной проверкой сертификата, без redirects; HTTP
только loopback debug. Local stop до remote revoke; node ACK/settlement проверяются
отдельно. Native timer не заменяет kernel cutoff. Нет production deployment.
