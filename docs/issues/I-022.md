# I-022 — manual subscriptions и source-aware quota

Статус: локальная backend реализация проверена; интеграция нового dataplane
явно закрыта до I-024. Scope: настоящий PostgreSQL backend,
immutable plan revisions, subscription/admin-grant, funding lots/allocations,
expiry/revocation без подмены measured usage и authenticated read API.
ADR-035 фиксирует period/renewal/addon/rewards/cancellation policy.

Изменяемые файлы: db/models.py, migration 0012, subscriptions.py, quota
contracts/service, безопасный gate tunnels/service, main/OpenAPI, тесты,
quota parser клиента при необходимости, ADR/runbook/verification.
Проверки: upgrade/backfill/drift/protected downgrade, real PostgreSQL races,
expiry/scheduled periods/revoke/idempotency/conflicts, user isolation,
неизменяемость, rewards/referrals/usage/tunnel regression и backup restore.

Риск: mixed quota/held reservations. Legacy lease запрещён для subscription
accounts, grant запрещён при живом legacy tunnel. V3 allocation — I-024.
Admin HTTP writes и MFA не подменяются trusted Python service, это I-023.
