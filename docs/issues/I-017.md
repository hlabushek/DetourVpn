# I-017 — Telegram Mini App

Статус: реализовано локально, реальный Telegram запуск остаётся ручным gate.
Ветка: `codex/i-017-telegram-mini-app`. Дата: 2026-10-21.

Scope: серверный initData exchange, same account/ledger, ограниченные сессии,
Soft Orbit React/TypeScript кабинет, баланс, daily/clicker, устройства read-only,
последние 20 операций, light/dark, logout и честные ошибки без фиктивных данных.
ADR-029 фиксирует окно входа, replay, права, retention и границы заданий.

Файлы: `apps/telegram-mini-app/`, auth/mini_app, auth service/security,
config/main/devices, DB models + migration 0010, tests, OpenAPI, `.env.example`,
ADR-029, runbook, verification, README/ROADMAP. Native tunnel/client не менялись.

Приёмка: валидная подпись → существующий аккаунт и баланс; подделка/старый/будущий
payload → отказ; 10 concurrent exchanges → 1 session; replay → отказ;
owner isolation; Mini App не создаёт ключи/туннели; reward повтор не удваивает
ledger; байты >2^53 точны; rollback не повышает права сессий.

Тесты и границы доказательств: `../verification-i-017.md`.
