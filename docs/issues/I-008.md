# I-008 — usage sample ingestion

Одна issue, branch codex/i-008-usage-ingestion. Решения: ADR-004.

Реализованы internal UsageService и bounded local CLI: trusted bindings
(node/peer → device/user), explicit epoch open/reset с CAS, versioned reports,
rx+tx cumulative accounting, received/charged watermarks, durable receipts,
same-key/business-sequence replay protection, stale/late data, quota atomic debit,
pending при отказе и read-only reconciliation. Миграция 0005_usage_ingestion.
Начальная граница счётчиков — ноль; baseline не скрывает первые bytes.

Новый node registry/authenticated transport не входит сюда: I-009. Нет публичных
ingest/control routes, пользовательского выбора owner, native counters collector
или обещания actual cutoff. Node principal задаёт доверенный caller вне JSON;
CLI требует local DB credentials и не считается доказательством node identity.

Acceptance: restart/replay/reset; все permutations delivery; late retired epoch;
debt carry-forward; account-level concurrent admission; reset/report races; DB FK,
immutability, rollback и schema drift; projection corruption; separate-process CLI;
strict integer/aware timestamps/no browsing fields; no public mutation endpoints.

Runbook: ../runbooks/usage.md. Результат: ../verification-i-008.md.
Следующая I-009: registry узлов, capabilities и authenticated agent contract.
