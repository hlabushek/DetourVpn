# I-007 — quota ledger

Local implementation, 2026-10-18. Одна issue, branch codex/i-007-quota-ledger.

Реализованы quota_ledger и durable quota_operations receipts, integer bytes,
credit/debit, защита от двух видов replay, atomic owner lock, отказ вместо partial
debit, overflow guards, append-only DB guards, initial credit once/user при login,
read API /quota и /quota/history, snapshot pagination, manual reconciliation.

Security assumptions/retention: ADR-014. Migration 0004_quota_ledger; непустой
downgrade запрещён. Значение initial quota не установлено владельцем, default 0,
настройка VPN_INITIAL_QUOTA_BYTES. Ноль сохраняет once-only registration receipt.
Публичных mutation endpoints, default dev credit и административного MFA bypass нет.

Acceptance tests: accepted/rejected replay; source/key conflict; same-key и distinct
concurrent debits; generated integer model cases; BIGINT/float boundary; owner-only
API; one-time login grant; atomic rollback auth+quota; SQL immutability/FK; receipt
без ledger; tampered prefix/head; empty/nonempty rollback и no ORM drift; реальный
reconcile CLI без печати идентификаторов/credentials.

Результаты и команды: ../verification-i-007.md. Локальный запуск/сверка:
../runbooks/quota.md. Usage ingestion с node/peer/epoch/sequence/reset/late samples
не входит в I-007; следующая I-008. Реальный traffic enforcement не заявляется.
