# I-014 — Quota UI/history

Назначена 2026-10-21 запросом «Сделай следующий этап», после принятого I-013.
Зависимости: I-007/I-013. Решения и ограничения: ADR-026.
Physical local acceptance пройден 2026-10-21: `i-014-local-android.json`,
`passed=true`, реальные телефон/API/PostgreSQL, synthetic ledger events.
Статус: технически принят в локальном quota/history scope ADR-026.
36 Flutter tests, 69 PostgreSQL quota tests, 10 Android unit tests, lint,
debug/unsigned release builds и ограниченный APK audit прошли.

Acceptance:

- Начислено/списано/зарезервировано/доступно в точных целых bytes.
- История учтённых операций: дата, знак/сумма, источник, баланс после операции.
- Пагинация с фиксированной revision; обновление начинает новый снимок.
- Loading/empty/error/stale/retry, доступность при крупном шрифте.
- Отказ API не превращает старую сумму в подтверждённую новую; logout стирает RAM.
- Flutter formatter/analyze/test, Android unit/lint/debug/release builds.
- Согласованность телефона, реального API и disposable БД на синтетических events.

Файлы: `apps/client/lib/{quota,quota_screen,api,connection,main}.dart`, client tests,
`integration_test/client_api_test.dart`, `services/api/tests/test_i013_android.py`,
`scripts/run_i01{3,4}_android.ps1`, ADR-026, verification, README, ROADMAP.

Security: server ledger не изменяется клиентом, новых runtime dependencies нет;
TLS/redirect/session restrictions сохранены. Query разрешены только для числовых
history cursors. Auth/session данные не сохраняются и не выводятся. Test-only
seed route существует только в pytest app, отсутствует в production API.

Не входят: rewards/clicker (I-015), live usage counter, новые VPS gates,
платежи, публичный выпуск. Вся история аккаунта за пределами последних 500
операций и persistent/offline cache не реализуются этим этапом.

Фактические результаты и воспроизведение: `docs/verification-i-014.md`.
