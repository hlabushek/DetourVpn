Критерии приёмки:

- [x] Backup аутентифицированно зашифрован; plaintext dump не пишется на диск.
- [x] Dump и manifest всех public tables используют один snapshot при writers.
- [x] Новый случайный restore target, проверка строк/содержимого и ledger.
- [x] Неверный ключ/повреждение/неверный manifest отклоняются, cleanup проверен.
- [x] Параллельные drills не конфликтуют и не меняют источник.
- [x] Read-only alerts для DB/schema, nodes, peer commands, backup и диска.
- [x] Только codes/counts/UTC в выводе; fail-closed CLI, no URL/secret arguments.
- [x] Runbook: local reproduction, права, retention, ручное расписание и recovery.
- [ ] Регулярное off-host хранение, независимая доставка/heartbeat supervisor,
      staging installation и измерение эксплуатационного RPO/RTO — отдельный
      deployment gate, требующий одобрения. Не доказываются локальным drill.
