DetourVPN — закрытая бета для Windows
======================================

Как запустить
1. Распакуйте папку целиком (не запускайте файл из архива).
2. Запустите DetourVpn.exe. Windows покажет предупреждение SmartScreen:
   нажмите «Подробнее» → «Выполнить в любом случае». Приложение пока не подписано.
3. Подтвердите запрос администратора (UAC). Без него нельзя создать сетевой адаптер.
   Запрос появляется при каждом запуске.

Как удалить
Закройте приложение, удалите папку. Данные входа лежат в %LOCALAPPDATA%\DetourVpn — эту папку тоже можно удалить.

Ограничения беты
- Нет аварийной блокировки (kill switch): если VPN остановится, трафик пойдёт напрямую.
- Нет Always-on и автообновления. Только Windows 10/11, 64 бит.
- Правила по доменам не гарантируются, если программа использует зашифрованный DNS, ECH или кеш.

Исходный код
Сетевой движок основан на Amnezia Box (GPL-3.0-or-later). Точный исходный код и наши патчи лежат
в папке SOURCE, уведомления — в THIRD_PARTY_NOTICES.md. DetourVPN не связан с Amnezia.
Системный драйвер wintun.dll — WireGuard LLC.
