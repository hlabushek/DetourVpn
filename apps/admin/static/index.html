Пригласить тестера

  1. Отправьте человеку сообщение

    Готовый текст со ссылкой на бота. Скопируйте и отправьте любым способом.

  2. Человек открывает бота и присылает вам свой ID

    Пока доступа нет, Mini App показывает ему число (его Telegram ID) и кнопку «Скопировать ID». Принимайте только числа.

  3. Вставьте ID и добавьте человека

    ID не сохраняется в журнале и не показывается после добавления. Пометка видна только вам. После добавления человек просто открывает Mini App снова.

Приглашённые

Отозвать доступ:

Аккаунт будет отключён, сессии и VPN-подключения отозваны. Для подтверждения введите Telegram ID этого человека.

«Ждёт входа» — человек добавлен, но ещё не открывал Mini App. «Вошёл» — аккаунт создан. Отозванного человека можно пригласить заново.

Пользователи

Telegram username обновляется при каждом входе через Mini App и может устареть между входами. Поиск по username — точное совпадение без учёта регистра (ADR-110).

Серверы

«На связи» значит, что агент узла недавно отвечал. Это не доказывает, что VPN работает: проверяйте подключением с телефона.

Новый сервер добавляется с компьютера двумя командами: add_beta_node prepare и add_beta_node run (инструкция: docs/runbooks/beta-add-node.md).

Серверы из панели (3x-ui, Remnawave)

Отдельные серверы с панелью, протокол VLESS + Reality. Сервис хранит только зашифрованную ссылку и никогда не заходит в панель. Устройствам такие серверы пока не выдаются; на Android они не поддерживаются.

Добавить сервер из панели

Вставьте одну ссылку vless:// одного клиента из панели. Логин и пароль панели не нужны и не вводятся. Подписки (subscription) пока не поддерживаются.
