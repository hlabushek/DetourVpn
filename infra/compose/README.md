# Локальные зависимости — DEV ONLY

PostgreSQL 17 и Redis 7.2 закреплены digest; порты только на
127.0.0.1:15432 и 127.0.0.1:16379. PostgreSQL имеет локальный volume,
Redis эфемерный и без пароля: только доверенная машина без реальных данных.
Внутри сети Compose сервисы доступны друг другу; это не production стенд.
Команды: `docs/runbooks/local-development.md` в корне. API I-001 не использует
эти сервисы. Проверка YAML не означает запуск контейнеров.
